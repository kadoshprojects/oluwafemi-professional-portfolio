# Oluwafemi Adejumobi | Project Management, Controls & Infrastructure

Portfolio web application covering project management, project controls, healthcare & education workflow digitalisation, construction coordination, and municipal water operations learning in Calgary, Alberta.

## Run locally
Open `index.html` in a browser or serve the directory with a local static server (recommended so in-page `fetch()` previews in the Evidence Library work seamlessly).

## Deploy to GitHub Pages
1. Push repository contents to `main`.
2. In GitHub repository **Settings → Pages**, set source to **GitHub Actions**.
3. `.github/workflows/pages.yml` deploys the site automatically on pushes to `main`.

## Deploy to Netlify
1. Import the repository into Netlify.
2. Set publish directory to `.` and leave build command empty (`netlify.toml` is preconfigured).
