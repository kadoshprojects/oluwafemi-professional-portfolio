# Oluwafemi Adejumobi | Project Management, Controls & Infrastructure

A human-centred professional portfolio covering project management, project controls, healthcare digital transformation, construction experience and current municipal water operations learning.

## Run locally
Open `index.html` in a browser. No build command is required.

## Deploy to GitHub Pages
1. Create a GitHub repository, for example `oluwafemi-portfolio`.
2. Upload the contents of this folder to the repository root and commit to `main`.
3. Open **Settings → Pages**.
4. Set the publishing source to **GitHub Actions**.
5. The included workflow at `.github/workflows/pages.yml` deploys the static site on pushes to `main`.
6. After the workflow succeeds, GitHub Pages displays the public site URL in Settings → Pages.

GitHub Pages publishing guidance: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Also deploy through Netlify (recommended)
1. Sign in to Netlify.
2. Choose **Add new project → Import an existing project**.
3. Connect GitHub and select this repository.
4. Set the publish directory to `.` and leave the build command empty.
5. Deploy. Future pushes to the connected production branch will trigger new Netlify deployments.

Netlify guide: https://docs.netlify.com/start/quickstarts/deploy-from-repository/

## Suggested setup
- GitHub repository: public only after reviewing every file for confidential material.
- GitHub Pages: optional secondary public URL.
- Netlify: primary polished portfolio domain, connected to the same GitHub repository.
- Use GitHub Issues to track improvements and project case-study evidence that is approved for publication.

- No project budgets, quantified savings, actual performance results or confidential operational details have been invented.
